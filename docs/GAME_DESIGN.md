# Game Design Document — Project Spirit Ward

Version 0.2 | 27 ตุลาคม 2026 | Owner: ผู้ใช้ | Integration: Claude

## แนวคิด

Action RPG บน Roblox ธีมญี่ปุ่นแฟนตาซี มุมมอง 3D บุคคลที่สาม ผู้เล่นเป็นผู้ฝึกหัดปราบโยไค ช่วยหมู่บ้านเชิงเขาที่ม่านกั้นโลกคนเป็นและโลกวิญญาณกำลังแตกสลาย ต่อสู้กับภูตผี ดูดพลังมาผนึกอาวุธ และปลดปล่อยร่างผู้พิทักษ์เพื่อปราบต้นเหตุ โลกสมมติ ไม่ยึดประวัติศาสตร์ยุคใดแบบเคร่งครัด

ภาพจำ: โทริอิ ยันต์กระดาษ โคมกระดาษ หน้ากาก วิญญาณสีคราม และคาตานะที่เปลี่ยนเอฟเฟกต์เมื่อผนึก เป้าหมายอารมณ์คือผจญภัยลึกลับแต่เข้าถึงง่าย ไม่เน้นความสยองสมจริง ดูรายละเอียดที่ [Art Direction](ART_DIRECTION.md)

กลุ่มเป้าหมายเชิงออกแบบ: คนชอบ action RPG, สะสม และเล่นร่วมกับเพื่อน รองรับ desktop และ touch ตั้งแต่ต้น ไม่ใช้การกดถี่หรือปุ่มจำนวนมากเป็นเงื่อนไขหลัก

## เสาหลัก

1. การเคลื่อนที่และต่อสู้สนุกได้แม้ยังไม่มีของหายาก
2. วิญญาณจากการต่อสู้มีประโยชน์ที่เห็นได้ทันที
3. เปลี่ยนสายเล่นผ่านวิชาและผนึก ไม่พึ่งเพิ่มเลขอย่างเดียว
4. ร่วมต่อสู้แล้วได้รางวัลส่วนตัว ไม่แย่ง last hit
5. ทุกช่วงเล่นสั้นมีเป้าหมายจบได้ และมีเป้าหมายถัดไปชัดเจน

## รูปแบบโลกและกล้อง

ผู้ใช้ยืนยัน: 3D บุคคลที่สาม เดินอิสระบนพื้น X/Z กระโดดตามแนว Y กล้องหมุนและซูมได้ มีการป้องกันกล้องทะลุผนัง พื้นที่เป็นโซนขนาดกระชับเชื่อมกัน ไม่ล็อกตัวละครบนระนาบด้านข้าง

การโจมตีประชิดใช้ทิศการเล็งบนพื้นและพื้นที่ด้านหน้าผู้เล่น มี soft aim ช่วยเลือกศัตรูใกล้แนวเล็งในระยะและไม่มีกำแพงกั้น ใช้กฎเดียวกันบน desktop/touch; ยังไม่มี hard lock-on ในต้นแบบ การพุ่งใช้ทิศเดินปัจจุบัน หรือทิศหน้าตัวเมื่อหยุดนิ่ง มือถือแยกบริเวณลากกล้องจากปุ่มต่อสู้

MVP ใช้หนึ่ง place มีหมู่บ้านและพื้นที่ต่อเนื่องหนึ่งชุด เป้าหมายทดสอบเริ่มต้น 8 ผู้เล่นต่อเซิร์ฟเวอร์ ต้องวัดจริงก่อนเพิ่มจำนวน

## วงจรการเล่น

รับเป้าหมาย → สำรวจพื้นที่ 3D → อ่านท่าศัตรู → ต่อสู้/หลบ → ได้ EXP, เงิน, essence และเกจวิญญาณ → เสริมอาวุธหรือปลดวิชา → ท้าบอส → เปิดเป้าหมายต่อไป

ระยะสั้น 1–3 นาที: กลุ่มศัตรูและเควสต์ย่อย ระยะกลาง 10–20 นาที: เตรียมตัวและล้มบอสหนึ่งรอบ ตัวเลขเป็นเป้าหมายออกแบบ ไม่ใช่ผลวัดการเล่นจริง

## ขอบเขตการส่งมอบ

| ระยะ | เนื้อหา |
|---|---|
| Prototype / M1 | ห้อง greybox, อาชีพนักดาบ 1, basic attack, dash, ผีธรรมดา 1, ดูดวิญญาณ, แปลงร่าง 1 |
| Vertical slice / M2–M3 | หมู่บ้าน 1, พื้นที่ล่า 2, ศัตรูธรรมดารวม 4, บอส 1, เควสต์ 5, อาวุธเริ่มต้น 1, ผนึก 2, save/load, UI desktop/touch |
| Closed alpha / M4 | ขยายเป็น 3 อาชีพ, บททดสอบเปลี่ยนคลาส, tutorial ปรับจาก playtest, progression ถึง level 10 |
| หลัง alpha | คู่หู สารานุกรม สำนัก กิจกรรมร่วมกัน และพื้นที่ใหม่ตามข้อมูลผู้เล่น |

ยังไม่รวม: trading, auction, PvP, สงครามฝ่าย, guild war, pet gacha, Battle Pass, paid power, offline farming และโลกเปิดหลาย place

## การต่อสู้

- Basic attack คอมโบ 3 จังหวะ; ใช้ปุ่มเดียว; จังหวะและค่าความเสียหายอยู่ใน definition
- สกิลหลายตัวต่ออาชีพตามหัวข้อ "ระบบสกิล" (แทนแผนเดิม 3 ช่อง, Director 28 ต.ค. 2026)
- Dash หลบด้วยระยะเคลื่อนที่ มี cooldown; ยังไม่มี invulnerability จนกว่าจะมีเหตุผลจาก playtest
- ศัตรูมี Idle → Alert → Chase → Telegraph → Attack → Recover → Dead
- Prototype: ผู้เล่นชนะศัตรูทั่วไปในประมาณ 3–5 basic hits; ค่าจริงปรับจาก TTK
- UI แสดงท่าเตือนและพื้นที่โจมตีชัด เอฟเฟกต์ไม่บังสัญญาณบอส
- PvE เท่านั้นใน MVP; ไม่ทำ friendly fire
- เกิดใหม่ที่ checkpoint เมื่อ HP หมด ไม่เสียอุปกรณ์ เงิน หรือ EXP; encounter reset ตามกติกาใน contracts

## อาชีพ

| ID | ชื่อทำงาน | บทบาท | ทักษะตัวอย่าง | ระยะเริ่ม |
|---|---|---|---|---|
| blade | ซามูไร คาตานะ/ฝักดาบ | ประชิดเป็นวง | ฟันกวาด | Prototype |
| shade | นินจา ดาบสั้น | คล่องตัว/เดี่ยว | พุ่งผ่านเงา | M4 เล่นได้แล้ว |
| talisman | องเมียวจิ ยันต์/เครื่องราง | ระยะไกล/พื้นที่ | ยันต์พุ่ง, เขตยันต์ตรึง (ยังไม่ตรึงจริง) | M4 เล่นได้แล้ว |

ชื่ออาชีพเปลี่ยนตาม Director 28 ต.ค. 2026 (id เดิม)

**การเลือกอาชีพ (Director 28 ต.ค. 2026):** เลือกครั้งเดียวตอนเข้าเกมครั้งแรก (เมนูขึ้นเองจนกว่าจะเลือก) **เลือกแล้วเปลี่ยนกลับไม่ได้** ปุ่มเลือกต้องกดยืนยันสองครั้ง ครูฝึกในหมู่บ้านใช้ดูอาชีพและอัปสกิล ไม่ใช่เปลี่ยนอาชีพ อาชีพขั้นสอง (แตกสาย) ออกแบบภายหลัง

## ระบบสกิล

ร่าง 28 ต.ค. 2026 ศึกษาหลักการจาก MMORPG แนวเดียวกัน (สกิลทยอยปลดตามเลเวล, แต้มสกิลไม่พอให้อัปทุกตัว, สกิลหลายประเภทต่ออาชีพ) แล้วออกแบบเอง ตัวเลขทั้งหมดเป็นค่าร่าง

- **เลเวลตัน 20** (เดิม 5) HP เพิ่มตามเลเวล
- **แต้มสกิล 2 แต้มต่อเลเวลอัป** อัปสกิลได้ทีละระดับ สกิลส่วนใหญ่สูงสุด 5–10 ระดับ รวมแล้วไม่พออัปทุกตัวเต็ม ผู้เล่นต้องเลือกทาง
- **สกิลขั้นแรก 8–10 ตัวต่ออาชีพ** ปลดทีละ 1–2 ตัวทุก 3–5 เลเวล ช่วงแรกเน้นตี ช่วงหลังเพิ่มควบคุม บัฟ และสกิลใช้งาน
- **ประเภทที่ทุกอาชีพมี** (น้ำหนักต่างกัน): ตีหลัก, พื้นที่, เคลื่อนที่, ควบคุม (ตรึง/กระเด็น), บัฟ, ติดตัว 2 ตัว
- **พลังวิญญาณ (SP)** แถบแยกจากเกจแปลงร่าง สกิลกดใช้ SP ฟื้นเองช้า ๆ
- **แถบสกิลปุ่ม 1–8** ผูกสกิลเองได้ มือถือใช้ปุ่มหน้าจอสลับหน้า
- สกิลพิเศษ 1–2 ตัวต่ออาชีพได้จากเควสต์
- ลำดับทำ: (1) เลือกอาชีพครั้งเดียว + เลเวล 20 + เก็บแต้มสกิล (2) SP + สกิลอาชีพละ 4–5 ตัว + แถบปุ่ม + เมนูอัปสกิลที่ครูฝึก (3) เติมจนครบ 8–10 ตัว และควบคุมศัตรูจริง

## วิญญาณและแปลงร่าง

แยกเป็นสองค่าเพื่อไม่ให้ผู้เล่นต้องเลือกระหว่างความสนุกกับการเก็บเงิน:

- **Spirit Gauge:** 0–100, ชั่วคราว, ใช้แปลงร่าง ไม่บันทึกข้าม session
- **Essence:** ทรัพยากรถาวร ใช้ผนึกอาวุธ บันทึกใน profile

server ให้ reward เมื่อ enemy death ผ่านการตรวจสอบ; orb ที่ client เห็นเป็นภาพของ reward เท่านั้น ไม่ต้องส่ง remote เพื่อขอรับซ้ำ

ต้นแบบผีทั่วไปให้ gauge 10; แปลงร่างเมื่อเต็มใช้ gauge ทั้งหมด มีผล 12 วินาที ระหว่างแปลงไม่เติม gauge ตายหรือออกเกมจบร่าง ร่างเริ่มต้นเปลี่ยน basic attack ให้เกิดคลื่นระยะสั้นและเปลี่ยน animation ไม่ใช้การขยาย model อย่างเดียว

## อุปกรณ์และผนึก

มี weapon slot เดียวใน slice; หนึ่งอาวุธติดหนึ่งผนึก ไม่มี durability และไม่แตก อัปเกรดขั้นต้นสำเร็จแน่นอน ยังไม่สุ่มคุณภาพหรือออปชัน

- ember: โจมตีครบเงื่อนไขติด burn; ไม่ซ้อน burn ไม่จำกัด
- ward: ดูดวิญญาณครบเงื่อนไขได้ shield; มี cooldown

การเปลี่ยนผนึกเริ่มต้นไม่เสียผนึกเก่าเพื่อเปิดให้ทดลอง การซื้อ/อัปเกรดดำเนินการที่ shrine ใช้ราคาใน config ตัวอย่างสมดุล: ศัตรูแรกให้ 3 essence; ผนึกแรก 30 essence เป้าหมายได้ลองภายในช่วง tutorial ต้องวัดเวลาจริง

## โลก เควสต์ และบอส

หมู่บ้านโคมสุดท้ายเป็น safe hub แบบหมู่บ้านไม้ญี่ปุ่นเชิงเขา เชื่อมป่าม่านหมอกที่มีไผ่และทางโคมไฟ แล้วไปศาลเจ้าร้างหลังประตูโทริอิ พื้นที่ล่าแต่ละแห่งมี checkpoint และ landmark อ่านง่าย ทางหลักเห็นจุดหมายจากกล้องบุคคลที่สาม มีลานต่อสู้กว้างพอให้หมุนกล้องและหลบรอบศัตรู หลีกเลี่ยงกิ่งไม้/อาคารบังท่าโจมตี

โครงเควสต์ 5 ขั้น: พบผู้ดูแลศาล → ฝึกปราบผี → สะสมร่องรอย → ทดลองผนึก → ปราบผู้เฝ้าศาล เควสต์หลักเป็น one-time; มี repeatable หลังจบเนื้อเรื่องโดยไม่แจกของ one-time ซ้ำ

บอสชื่อทำงาน “ผู้เฝ้าโคมดับ” เป็นผู้พิทักษ์สวมหน้ากากแตกร้าวในชุดคลุมญี่ปุ่นแฟนตาซี มี 3 ท่า: กวาดโคมเป็นส่วนโค้ง, พื้นที่อาคมวงกลมบนพื้น, เรียกวิญญาณช่วย มี telegraph ทุกท่าและช่วงเปิดช่องให้โจมตี ตั้งเป้ารอบบอส 2–4 นาที solo ด้วยอุปกรณ์ระดับเดียวกัน ต้องเล่นทดสอบ

บอสใช้ encounter arena ร่วมในเซิร์ฟเวอร์ เปิดรับก่อนเริ่ม ไม่เติมผู้เล่นกลาง encounter ผู้ตายหมดสิทธิ์รอบนั้นและกลับ checkpoint ถ้าสมาชิกตาย/ออกครบให้ reset ไม่มีรางวัล

## รางวัลและ progression

server แจก EXP, coins และ essence ส่วนตัวให้ผู้ร่วมโจมตีที่เข้าเกณฑ์ ไม่แชร์ orb ที่แย่งกันเก็บ EXP ใช้ curve ใน data; cap level 10 สำหรับ alpha การเพิ่ม level ปรับ HP/พลังพื้นฐานตาม config

ไม่ทำของดรอปที่ขายด้วยเงินจริงในระยะแรก เมื่อเต็ม inventory ต้องปฏิเสธ grant ที่ต้องเพิ่ม item ก่อนหักต้นทุน ส่วน currency ใช้เพดานที่กำหนดและแสดงผลชัด

## UX และงานภาพเสียง

HUD: HP, spirit gauge, skill cooldown, quest tracker และปุ่มแปลงร่าง ปุ่มมือถือไม่เกิน basic, dash, jump, skill slots และ transform; milestone แรกใช้ skill เพียงหนึ่งช่อง

แสดงผล rejected action เช่น cooldown/ไม่มี essence ด้วยข้อความสั้น รองรับปิด camera shake ลด flash และปรับเสียง ไม่สื่อท่าอันตรายด้วยสีเพียงอย่างเดียว

ศัตรูใช้ silhouette ต่างกัน พื้นหลังมืดกว่าตัวละคร เอฟเฟกต์สะสมวิญญาณสั้นและอ่านง่าย asset ยังเป็น greybox จน gameplay ผ่าน M1

## การหารายได้

ยังไม่มีร้าน Robux ในต้นแบบ/vertical slice แนวทางหลังทดสอบคือชุด รูปลักษณ์อาวุธ และเอฟเฟกต์ที่ยังอ่านท่าต่อสู้ได้ ต้องออกแบบและทบทวนแยกก่อนเปิดขาย

## สิ่งที่วัดในการเล่นทดสอบ

- ผู้เล่นใหม่เดิน/โจมตี/หลบได้โดยไม่ให้คนสอนภายใน 2 นาทีหรือไม่
- ได้ลองแปลงร่างครั้งแรกภายใน 5 นาทีหรือไม่
- รู้ว่าจะไปไหนต่อหลังจบเควสต์หรือไม่
- เวลาชนะศัตรู, จำนวนตายต่อ encounter, เวลาบอส และเหตุผลที่หยุดเล่น
- ผลทดสอบผู้เล่น 1/2/8 คน และ touch จริง; ยังไม่มีตัวเลข retention เป้าหมายจนมี baseline

ตัวเลขทั้งหมดในเอกสารนี้เป็นค่าทดลอง v0.1 ไม่ใช่สิ่งยืนยันจากการเล่นจริง
