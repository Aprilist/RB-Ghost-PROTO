# Japanese Fantasy Art Direction v0.2

ผู้ใช้ยืนยันธีมญี่ปุ่นและกล้อง 3D บุคคลที่สาม วันที่ 27 ตุลาคม 2026 รายละเอียดด้านล่างเป็นแนวทางออกแบบเริ่มต้น ปรับได้จาก greybox/playtest

## โลกและอารมณ์

ญี่ปุ่นแฟนตาซีในโลกสมมติ หมู่บ้านเชิงเขาเผชิญม่านวิญญาณแตก ผู้เล่นเป็นนักปราบโยไคฝึกหัด สำรวจช่วงโพล้เพล้ถึงกลางคืน อบอุ่นเมื่ออยู่หมู่บ้าน ลึกลับเมื่อเข้าป่า และกดดันเมื่อถึงศาลเจ้าร้าง ใช้ตัวละครและเรื่องราวต้นฉบับ ไม่ผูกกับเรื่องหรือจักรวาลอนิเมะใด

ภาพ stylized รูปทรงชัด รายละเอียดพออ่านจากระยะกล้องต่อสู้ เน้นไม้ หิน เชือก กระดาษ และผ้า หมอกเป็นฉากหลังแต่ไม่ลดการมองเห็นท่าเตือน ไม่มีเลือดหรือความสยองสมจริง

## สถานที่ใน slice

| ที่ | ชุดภาพ/landmark | หน้าที่ gameplay |
|---|---|---|
| หมู่บ้านโคมสุดท้าย | บ้านไม้ หลังคาลาด โคมกระดาษ ต้นไม้กลางลาน ร้านตีดาบ | safe hub, tutorial, shrine upgrade; เดินเห็นทางออกชัด |
| ป่าม่านหมอก | ไผ่ รากไม้ หิน ทางโคมไฟ และสะพานไม้ | ฝึกหลบ/อ่าน telegraph; มีลานสู้ต่อเนื่อง ไม่อัดต้นไม้บังกล้อง |
| ศาลเจ้าร้าง | โทริอิ บันไดหิน เชือก/ยันต์ ประตูศาล และลานหิน | พื้นที่ล่า 2 และ boss arena; ศัตรูบนบันไดต้องตรวจ height |

ไม่เพิ่ม biome ใหม่ใน MVP ใช้ modular kit เดียวปรับแสง/วัสดุ/สัดส่วนเพื่อควบคุมปริมาณงาน

## ตัวละครและอุปกรณ์

- blade: นักดาบผนึก ชุดผ้าสั้นคลุมเกราะเบา คาตานะและฝักดาบ silhouette ชัด
- shade: ชิโนบิเงา ผ้าพันแขน/ผ้าคลุมสั้น ดาบสั้น ไม่ใช้เสื้อผ้าพลิ้วบังเป้าหมาย
- talisman: องเมียวจิแฟนตาซี ชุดคลุมพอดีตัว ยันต์กระดาษและเครื่องราง อ่านต่างจากนักดาบ
- ร่างผู้พิทักษ์ต้นแบบ: หน้ากากเรืองแสง ลายอาคมและออร่าคราม เปลี่ยนท่าต่อสู้ เก็บรูปทรงมนุษย์และ hitbox เดิม
- training_blade เป็น stable definition ID เดิม แต่ภาพเป็นคาตานะฝึก ไม่เปลี่ยน ID เพียงเพราะเปลี่ยนธีม

## ศัตรูที่ต้องส่งให้ Claude ทำรายละเอียด

| stable ID | ภาพตั้งต้น | วิธีแยก silhouette |
|---|---|---|
| lantern_wisp | โคมกระดาษถูกวิญญาณสิง | ลอยตัว ลำตัวกลม มีเปลวไฟเล็ก |
| root_shade | ภูตตอไม้/รากไม้ | ตัวเตี้ย กว้าง แขนรากไม้ |
| bell_moth | ภูตแมลงคืนที่แบกระฆังเล็ก | ปีกชัด ขยับเร็ว |
| shrine_guard | ผู้เฝ้ายันต์ไร้หน้า | รูปร่างสูง แผ่นยันต์รอบแขน |
| extinguished_keeper | บอสผู้เฝ้าโคมดับ หน้ากากแตกและโคมใหญ่ | สูงกว่าศัตรูทั่วไป ไหล่กว้าง อาวุธอ่านทิศชัด |

ทั้งหมดเป็น creature concepts สำหรับเกม ไม่ใช่การอ้างว่าตรงกับตำนานญี่ปุ่นเฉพาะเรื่อง

## สี แสง และ UI

- พื้นโลก: คราม/เทาหม่น ตัดโคมสีอำพัน; โทริอิสีแดงหม่นเป็น landmark
- พลังผู้เล่น: ครามฟ้า/ขาว; ember ส้ม; ward ทองอ่อน
- พื้นที่อันตราย: ขอบแดงส้มร่วมลายและจังหวะเตือน ไม่ใช้สีเพียงอย่างเดียว
- HUD ใช้แผ่นกระดาษ/รอยหมึกอย่างเบาบาง ตัวอักษรไทยอ่านง่าย พื้นหลังทึบพอ; ไม่มีฟอนต์ตกแต่งในข้อมูลสำคัญ
- ไม่ใส่ซากุระ โทริอิ และหมอกทุกจุดจน landmark เหมือนกันหมด

## งานเสียง

แนวทาง: เสียงลม ใบไผ่ น้ำ โคม และระฆังเว้นจังหวะ; combat ใช้เสียงคมดาบ กระดาษยันต์ และเสียงดูดพลังที่สั้น ชัด ท่าโจมตีใหญ่มี cue ก่อนกระทบ ไม่เปิดเสียงระฆังหลายตัวทับกันจนแยกไม่ได้ ต้องใช้เสียงสร้างเองหรือมีสิทธิ์ใช้งานและลงที่มาใน manifest

## เกณฑ์ asset และกล้อง 3D

สร้าง greybox ก่อนงานละเอียด ทดสอบมองหลังตัวละคร/ข้างผนัง/ใต้หลังคาและบนบันได โมเดลเสาต้องมี collision เหมาะสม ใบไม้/อนุภาคตกแต่งไม่ขวางการตรวจโจมตีหรือการเดิน AI สัญญาณโจมตีอ่านได้ทั้งพื้นไม้ หิน และดิน

Claude ส่ง art brief, รายการ modular assets และข้อกำหนด animation ภายใน CL-01/CL-02 ยังไม่ต้องสร้าง asset production จน M1 ผ่าน Codex รับเข้า manifest และทดสอบใน Studio ตามลำดับ
