# M2-D เควสและ NPC — ผลทดสอบและรายการให้ Director ลอง

ร่างโดย Claude 27 ต.ค. 2026 | สถานะ: **ส่ง source แล้ว ยังไม่ได้ compile/รันจริง รอ Director กด Play**

ทิศทางจาก Director: ทำ gameplay ให้ครบก่อนแล้วค่อยเก็บภาพทีเดียว จึงทำให้อ่านง่ายพอ ไม่ขัดเกลาภาพ; ผีอ่อน ๆ เท่านั้น; เหรียญแสดงอย่างเดียว; ยังไม่มี save จริงจนถึง M3

## สิ่งที่ทำ

| ส่วน | สรุป |
|---|---|
| ข้อมูล | `Definitions/Quests` (เป้า q02, `giverNpcId`, `objectiveTH`), `Definitions/Npcs` (ใหม่), `World.Mistwood.veilTraces` (3 จุด ในลานโล่งรอบจุดเกิดผีซึ่งไม่มีต้นไม้) |
| กฎ (pure) | `Shared/Util/QuestRules.luau`: เริ่มเควส/prerequisite, นับ objective, claim ครั้งเดียว, สถานะของผู้ให้เควส; client ใช้ไฟล์เดียวกันวาด "!" / "?" |
| Server | `QuestService` (ใหม่): เควสเปลี่ยนผ่าน `ProfileService.Mutate` เท่านั้น, kill นับจาก `RewardService.OnGranted` (ใหม่), claim_quest จ่ายรางวัลใน mutation เดียวกับที่ mark claimed แล้วเสนอเควสถัดไปต่อทันที; `NpcService` (ใหม่): หุ่น NPC และเศษม่านพร้อม ProximityPrompt ปุ่ม F, server ตรวจระยะ/alive/cooldown เอง ไม่มีอะไรชนได้ |
| เครือข่าย | เปิด `claim_quest {questId}`, snapshot มี `quests`, StateEvent ใหม่ `dialogue` และ `notice` (รายละเอียด `handoff/M2D_CONTRACT_PROPOSALS.md`) |
| Client | `QuestController` (ใหม่): ลูกศรนำทางบนพื้น (`Util/QuestGuide` ตัดสินหมาย), ตัวติดตามเควสใต้ HUD, กล่องบทพูดกลางจอพร้อมปุ่ม "รับรางวัล"/"ปิด" (ปิดเองเมื่อเดินห่าง), ข้อความแจ้งสั้น ๆ, เครื่องหมายเหนือหัวผู้ให้เควส; CombatController ไม่แสดง error ของ claim_quest ซ้ำ |
| Test | ใหม่ `QuestRulesTest` 11 ข้อ (pure) และ `QuestWorldTest` 6 ข้อ (ข้อสุดท้ายต้องมีฉาก) รันเองตอนกด Play |

## ผลทดสอบนอก Studio (Claude, 27 ต.ค. 2026)

- **ยังไม่ได้ compile และยังไม่ได้รัน Luau**: เครื่องที่ใช้รอบนี้ไม่มี `luau` และดาวน์โหลดไม่ได้ ตรวจด้วยการอ่านโค้ดเท่านั้น
- ตรวจตัวเลขตำแหน่งด้วย Python: NPC แผงขายห่างถนนใกล้สุด 28 studs, ผู้ดูแลศาลห่าง 141 studs, ไม่มีใครอยู่ในแปลงบ้าน; เศษม่านห่างจุดเกิดผี 5.7–7.2 studs (ในรัศมีลานโล่ง 11)
- ไล่ EXP ทั้ง 5 เควสด้วยมือ: รวม 200 EXP จบที่เลเวล 4 (EXP 10/150) ผ่านกฎ ProfileRules

**ยังไม่ได้ตรวจ:** strict type-check, Studio จริง, หน้าตา NPC/กล่องบทพูดบนจอจริงและมือถือ, 2 clients

## ข้อจำกัดที่ตั้งใจ

- เศษม่านที่เก็บแล้วยังมองเห็นอยู่ (ทุกคนเห็นเหมือนกัน) เก็บซ้ำไม่นับ
- ชิ้นที่เก็บไปจำไว้ในรอบเล่นเท่านั้น (เหมือน profile ทั้งหมดจนถึง M3)
- NPC เป็นหุ่นจาก Part ไม่มี animation ไม่หันตามผู้เล่น
- ลูกศรนำทางเป็นภาพฝั่ง client ชี้ไปที่หมายเดียวของเควสแรกที่ยังไม่รับรางวัล (เศษม่านชี้ชิ้นที่ใกล้ที่สุด ไม่รู้ว่าชิ้นไหนเก็บแล้ว)
