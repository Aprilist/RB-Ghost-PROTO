# M2-C ผีญี่ปุ่นในป่า Mistwood — ผลทดสอบและรายการให้ Director ลอง

ร่างโดย Claude 27 ต.ค. 2026 | สถานะ: **ส่ง source แล้ว ยังไม่ได้ compile/รันจริง รอ Director กด Play**

ทิศทางจาก Director (27 ต.ค. 2026): ผีร่มและผีพื้นฐานของญี่ปุ่น เอา**ผีอ่อน ๆ ก่อน ผีในขบวนร้อยอสูร (Hyakki Yagyō) เก็บไว้ทีหลัง** แต่**เก็บผีร่มไว้ในชุดแรก** (เลือกบนการ์ด)

## ผีชุดแรก

แทน `root_shade` และ `bell_moth` (ร่างเดิมในแผน M2 ไม่มีอะไรอ้างถึง) `shrine_guard` ของศาลเจ้าร้างยังเป็นร่างเหมือนเดิม

| ผี (catalog id) | ท่าทาง | ท่าเตือน (รูปทรง) | HP / ตี / เตือน / เร็ว | รางวัล XP / เหรียญ / essence / เกจ | จุดเกิด |
|---|---|---|---|---|---|
| ผีโคม `lantern_wisp` (เดิม) | ลอยเข้าหา | วงแดงรอบตัว (burst) | 60 / 10 / 0.8 วิ / 8 | 10 / 2 / 5 / 10 | ลาน 3 จุด (ไม่เปลี่ยน) |
| ฮิโตดามะ `hitodama` | ดวงไฟผีสีเขียวขาว มาเป็นคู่ ลอยเร็ว | แถบตรงยาว 8 กว้าง 3 แล้วพุ่งชนไปสุดแถบ (charge) | 40 / 6 / 0.7 วิ / 11 | 8 / 1 / 3 / 8 | 2 จุดฝั่งหมู่บ้าน × 2 ตัว |
| โคดามะ `kodama` | วิญญาณต้นไม้ตัวเล็กสีขาว เดินต้วมเตี้ยม | วงรอบตัวรัศมี 6 (burst) | 50 / 8 / 0.9 วิ / 6 | 9 / 2 / 4 / 10 | 2 จุดกลางป่า |
| ผีร่ม `karakasa` | ร่มกระดาษตาเดียว ลิ้นยาว กระโดดขาเดียว | วงรัศมี 4 ตรงจุดที่ผู้เล่นยืน (ไกลสุด 10) แล้วกระโดดลงทับ (leap) | 70 / 10 / 0.9 วิ / 8 | 14 / 3 / 5 / 10 | 2 จุดฝั่งลานศาลเจ้า |

ค่าทั้งหมดอยู่ใน `Definitions/Enemies.luau` เป็นค่าเริ่มต้นให้ปรับหลังเล่นจริง ดาบพื้นฐานตี 20 จึงใช้ 2 / 3 / 4 ครั้งตามลำดับ

## สิ่งที่ทำ

| ส่วน | สรุป |
|---|---|
| Catalog | `tuning` เพิ่ม `attackShape` (burst/charge/leap/lunge), `attackWidthStuds`, `groupSize`, `steer` ผีโคมได้ `burst`, `groupSize 1`, `steer false` ค่า P1 ทุกตัวเท่าเดิม |
| กฎการโจมตี (pure) | `Util/EnemyAttackRules.luau`: ตอนเริ่มเตือน server กำหนดพื้นที่โจมตีจากตำแหน่งผีกับผู้เล่น (ตัดสั้นเมื่อชนกำแพง/ต้นไม้ และไม่ให้พุ่ง/กระโดดออกนอกรัศมี leash) ป้ายบนพื้นแสดงพื้นที่นั้น และตอนจบเตือนก็ตรวจด้วยพื้นที่เดียวกัน เห็นอะไรก็โดนอย่างนั้น |
| EnemyService | รองรับหลายชนิด: marker บอกชนิดด้วย attribute `EnemyType` (ไม่มี = ผีโคม), จำนวนสูงสุดนับแยกชนิด, ป้ายเตือนเป็นวง/แถบตามรูปทรง, ผีที่ `steer` ลองเลี่ยงซ้าย/ขวา 45°/90° เมื่อชนต้นไม้; server ยังเป็นคนตัดสินการโดนตีทั้งหมด |
| โมเดล | `Enemies/Models.luau` (ใหม่): ผีโคมย้ายมาโดยหน้าตาเท่าเดิม + ฮิโตดามะ โคดามะ ผีร่ม ทำจาก Part ล้วน ระหว่างเตือนตัวผีเปลี่ยนเป็นสีส้มแดง |
| CombatService | ระยะเผื่อตัวผีตอนฟันใช้ `bodyRadiusStuds` ของแต่ละชนิด (ผีโคมยัง 1.5) |
| ป่า | `World.Mistwood.enemySpawns` ระบุชนิด, `Mistwood.luau` ติด tag `EnemySpawn` ให้ 6 จุด |
| เสียง | เสียงเตือนสูงต่ำต่างกันตามชนิด (ผีโคมเท่าเดิม) |
| Test | ใหม่ `EnemyAttackRulesTest` 9 ข้อ; `CatalogTest` เพิ่ม 2 ข้อ (รูปทรง/กลุ่ม/มีโมเดล, จุดเกิดในป่าเป็นผีป่าและรัศมี leash อยู่ในโซนให้รางวัล) |

## ผลทดสอบนอก Studio (Claude, 27 ต.ค. 2026)

- **ยังไม่ได้ compile และยังไม่ได้รัน Luau**: เครื่องที่ใช้รอบนี้ไม่มี `luau`/`luau-compile` และดาวน์โหลดไม่ได้ ไฟล์ทั้งหมดตรวจด้วยการอ่านเท่านั้น
- คณิตของ `EnemyAttackRules` ตรวจด้วยสำเนา Python ทุกข้อใน `EnemyAttackRulesTest` ผ่าน (burst ขอบวง, charge ตามแถบ/หลัง/เลยปลาย/ข้าง, ชนกำแพงแล้วสั้นลง, leap ลงตรงจุด/ไกลสุด/ชนกำแพง, lunge, รัศมี leash)

**ยังไม่ได้ตรวจ:** strict type-check, Studio จริง, หน้าตาผีจากมุมกล้อง, การเดินอ้อมต้นไม้, ความยาก, 2 clients, มือถือ

## ข้อจำกัดที่ตั้งใจ

- ผีในขบวนร้อยอสูร (เช่น ผีคอยาว) และกัปปะเก็บไว้รอบหลังตามที่ Director บอก
- ยังไม่มี animation จริง ผีขยับด้วยการโยกตัว/กระโดดขึ้นลงอย่างเดียว ผีร่มยังไม่หุบร่มตอนเตือน (ใช้เปลี่ยนสีแทน)
- ผีเลี่ยงต้นไม้แบบง่าย (ลองเลี้ยว) ไม่ใช่ waypoint เต็มรูปแบบ
- ไฟเรืองของผีใน Runtime รวมประมาณ 16 ดวงเมื่อเกิดครบ ยังไม่ได้วัด performance
