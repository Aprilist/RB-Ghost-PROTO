ร่างโดย Claude 27 ต.ค. 2026 | สถานะ: **ส่ง source แล้ว ยังไม่ได้ compile/รันจริง รอ Director กด Play** (ต่อจาก M2-D ซึ่งก็ยังไม่เคยรัน)

## สิ่งที่ทำ

| ส่วน | สรุป |
|---|---|
| กฎ (pure) | `Server/Util/SealRules.luau`: ซื้อผนึก (ตรวจ+หักแก่นวิญญาณครั้งเดียว), ตัวนับ ember, ไฟไม่ซ้อน, ตัวนับ ward, กองโล่ |
| Server | `SealService` (ใหม่): `apply_seal`, ember (burn ผ่าน `EnemyService.Damage` ทุก 0.5 วิ จึงได้รางวัลตามปกติ), ward (นับจาก `RewardService.OnGranted`) |
| ที่ต่อเพิ่ม | `CombatService.OnBasicHit` (ฟัง basic attack ที่โดน), `PlayerStateService` มีโล่ (ดูดซับดาเมจก่อน HP, ล้างเมื่อตาย/เกิดใหม่) และ snapshot ส่ง `equippedWeaponId/equippedSealId/shieldHp/shieldEndsAt`, `ProfileRules.Validate` ปฏิเสธ sealId นอก catalog |
| NPC | ช่างตีดาบ (`npc_smith`) เป็นจุดผนึก: ปุ่ม F "ผนึกดาบ" เปิดเมนู แทนการคุยทั่วไป |
| Client | `SealController` (ใหม่): เมนู 2 ผนึก แสดงผล/ราคา/สิ่งที่ติดอยู่, HUD แสดงผนึกและโล่ (+คูลดาวน์ ward), เอฟเฟกต์ `burn` / `ward_shield` / `seal_apply` |
| เควส | q04 ใช้ได้จริง (ไม่ draft) เป้าหมายคือช่างตีดาบ ข้อความเควสแก้ตามนั้น; `QuestService.Record("apply_seal")` ถูกเรียกหลังผนึกสำเร็จ |
| Contract | ข้อเสนอทั้งหมดอยู่ใน `handoff/M2E_CONTRACT_PROPOSALS.md` รวมข้อเสนอปิด DEC-008 |

ตัวเลข (ราคา 30, ember 3 ครั้ง/4 ต่อวิ/3 วิ, ward 3 ดวง/โล่ 25/8 วิ/คูลดาวน์ 15 วิ) ยังเป็นค่า draft ใน `Definitions/Seals` ไม่ได้ปรับจากการเล่นจริง

## ผลจาก Director (27 ต.ค. 2026)

- Director ทดลองใน Studio แล้วแจ้งว่า "ผนึกผ่าน" ไม่ใช่การยืนยันรายข้อ E1–E10 ทั้งหมด
- เรื่องสลับผนึก: **คงแบบปัจจุบันไว้ก่อน** (จ่ายราคาใหม่ ผนึกเก่าหลุด) Director จะกลับมาออกแบบระบบผนึกให้เต็มรูปทีหลัง

## ข้อจำกัดที่ตั้งใจ

- เปลี่ยนผนึกต้องจ่ายใหม่และผนึกเก่าหลุด (ดูข้อ 8 ใน M2E_CONTRACT_PROPOSALS) Director ให้คงไว้ก่อน
- เมนูผนึกเป็น UI greybox ยังไม่มีหน้ายืนยันราคาแยก (กด "ผนึก" แล้วหักทันที) แผน M2 ระบุ "หน้ายืนยันราคา" ถ้า Director ต้องการให้เพิ่ม
- ตัวนับ ember/ward ไม่แสดงบน HUD (แสดงแค่ผนึกที่ติด และคูลดาวน์ ward)
- ยังไม่มีอัปเกรดอาวุธ (InventoryService เต็มรูปไม่อยู่ใน M2-E รอบนี้ มีแค่ผนึกบนอาวุธเริ่มต้น)
- burn ติดเฉพาะศัตรูธรรมดา ยังไม่มีบอส (M2-F) ต้องดูเรื่องบอสกับ burn ตอนนั้น
