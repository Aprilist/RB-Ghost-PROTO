# M2-F — ส่วนที่เพิ่มเข้า contract (ข้อเสนอ)

ร่างโดย Claude 27 ต.ค. 2026 | สถานะ: **ใช้ในโค้ด M2-F แล้ว รอ Codex รับเข้า docs/CONTRACTS.md** ทุกข้อเป็นการ "เพิ่ม" ไม่ลบหรือเปลี่ยนชื่อของเดิม

## 1. StateEvent `encounter` (มีใน CONTRACTS แล้ว เพิ่ม field เดียว)

`{kind, encounterId, state, endsAt?}` ตาม contract เดิม เพิ่ม `joined: boolean`

| field | ความหมาย |
|---|---|
| `encounterId` | `<bossId>:<รอบ>` เช่น `extinguished_keeper:3` รอบใหม่เมื่อเปิดสนามใหม่ |
| `state` | `open` (เปิดรับ), `fighting` (ล็อกแล้ว), `won` (บอสล้ม), `reset` (เลิกกลางคัน บอสกลับเต็มเลือด) |
| `endsAt` | ใช้เฉพาะ `open`: เวลาที่จะล็อก (server clock) |
| **`joined` (ใหม่)** | `false` เมื่อผู้เล่นไม่อยู่ในศึกนี้ เช่น มาหลังล็อก หรือตาย/ออกจากลานแล้ว client ใช้แสดงข้อความ "รอรอบหน้า" แทนแถบเลือด |

ส่งให้สมาชิกรอบนี้ (รวมคนที่เพิ่งตาย เพื่อให้รู้ผลจบ) และคนที่ยืนอยู่ในลาน ไม่ส่งให้คนอื่น

## 2. HP ของบอสไม่ส่งผ่าน remote ใหม่

client อ่านจาก Attribute ของ model บอสที่ replicate อยู่แล้ว (`Hp`, `MaxHp`, `State`, `Open`) จึงไม่เพิ่ม traffic ต่อการโจมตี ถ้า Codex ต้องการให้ HP ผ่าน StateEvent แทน บอกได้

## 3. กติกาสนาม (ตามที่ contract/GDD ระบุ ผมตีความเป็นโค้ดดังนี้ — ขอรับรอง)

| กติกา | ที่ทำ |
|---|---|
| เปิดรับก่อนเริ่ม | ผู้เล่นคนแรกที่ยังไม่ตายเดินเข้าลาน เปิดหน้าต่าง 8 วินาที (`joinWindowSec`) ใครเข้ามาในหน้าต่างนี้เป็นสมาชิก ออกจากลานก่อนล็อกแล้วกลับเข้ามาได้ |
| ไม่เติมกลางศึก | หลังล็อก คนที่เข้ามาไม่ใช่สมาชิก: บอสไม่เล็งคนนั้น ดาเมจของคนนั้นไม่นับ ไม่มีรางวัล และได้ข้อความแจ้ง |
| ผู้ตายหมดสิทธิ์ | สมาชิกที่ตายหรือเดินออกนอกลานหลังล็อก ถูกตัดออกจากรอบนั้นถาวร (กลับมาก็ไม่ใช่สมาชิก) |
| ทุกคนตาย/ออก | ไม่มีสมาชิกที่ยังรอดในลาน 5 วินาที (`resetAfterEmptySec`) บอส reset เต็มเลือด ไม่มีรางวัล |
| รางวัล | ตอนบอสล้ม สมาชิกที่ยัง alive และอยู่ในลาน และทำดาเมจสะสม ≥ 5% ของเลือดสูงสุด ได้รางวัลเต็มหนึ่งครั้ง (ledger กันซ้ำด้วย `bossRuntimeId:userId`) คนอื่นไม่ได้ |
| บอสกลับมา | 45 วินาทีหลังล้ม (`respawnSec`) เปิดรอบใหม่ได้ |

## 4. รางวัลและเควส

- รางวัลบอสเป็นค่าคงที่ใน `Definitions/Bosses` (EXP 60, เหรียญ 20, แก่นวิญญาณ 15 ค่า draft) จ่ายผ่าน `RewardService.GrantFixed` และ `ProfileService.Mutate` เหมือนรางวัลศัตรู
- สมาชิกที่ได้รางวัลถูกบันทึก `QuestService.Record(player, "defeat_boss", "extinguished_keeper")` q05 จะเป็น `ready` เมื่อ q05 ยัง active อยู่ แล้วรับรางวัลเควสที่ผู้ดูแลศาลด้วย `claim_quest` เหมือนเดิม
- ผีที่บอสเรียกไม่ให้รางวัลและไม่เกิดซ้ำ

## 5. ข้อสังเกตที่ Codex ควรตัดสิน

- ผีโคม 3 จุดเกิดเดิมในลานศาลเจ้า (จาก P1) ยังอยู่และให้รางวัลตามปกติ ถ้าไม่ต้องการให้อยู่ระหว่างบอส ให้ย้ายหรือปิดได้
- ลานบอสใช้โซน `p1_arena` (kind `test`) ไม่ได้ย้ายไปเป็น `abandoned_shrine` เพราะรางวัลบอสไม่ผ่านกฎโซนแบบศัตรูทั่วไป การตัดสินว่าอยู่ในลานใช้ขอบสี่เหลี่ยมใน `Definitions/Bosses`
- ไม่มี hard door: ผู้เล่นที่ไม่ใช่สมาชิกเดินเข้าลานได้ แต่ไม่ถูกบอสเล็งและทำดาเมจไม่ได้ ถ้าต้องการกั้นจริงต้องเพิ่มประตูในฉาก
