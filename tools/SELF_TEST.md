# ทดสอบเองใน 3 ขั้น (ไม่ต้องใช้ Codex)

ใช้ทดสอบระบบ server คุมการพุ่ง (P1-E) ใช้เวลาประมาณ 2 นาที

## 1. กด Play

ให้ Rojo เชื่อมอยู่ (หรือ sync โค้ดล่าสุดเข้า Studio) แล้วกด **Play** (F5)

เปิดหน้าต่าง **Output** (แท็บ View → Output) รอประมาณ 3 วินาที จะมีบรรทัดนี้ขึ้นเอง:

```
[MovementRulesTest] 15 passed, 0 failed
```

## 2. วางคำสั่งเดียวฝั่ง Client

1. แท็บ **Test** → ตรงกลุ่ม Clients and Servers ดูปุ่มที่เขียนว่า **Current: Server** กดให้เป็น **Current: Client**
2. เปิด Command Bar (แท็บ View → Command Bar) วางบรรทัดนี้แล้วกด Enter:

```lua
require(game.Players.LocalPlayer.PlayerScripts.Client.Tests.MovementQa).Run()
```

3. **ปล่อยมือจากคีย์บอร์ด/เมาส์** ประมาณ 20 วินาที ตัวละครจะเดินเอง วาร์ป ทะลุกำแพง และพุ่งเอง การถูกดึงกลับระหว่างนี้เป็นเรื่องปกติ

## 3. ส่งผลกลับมา

ใน Output ให้หาบรรทัดที่ขึ้นต้นด้วย `[MovementRulesTest]` และ `[QA]` โดยเฉพาะบรรทัดสุดท้าย:

```
[QA] SUMMARY 5/5 passed | PASS walk | PASS teleport | ...
```

คัดลอกบรรทัดเหล่านี้ หรือถ่ายภาพหน้าต่าง Output ส่งมาในแชต ถ้ามีข้อความสีแดงหรือสีส้มก็ส่งมาด้วย

## เพิ่มเติม (ถ้ามีเวลา)

- **รู้สึกตอนพุ่งเอง:** กด Stop แล้ว Play ใหม่ ลองกด Q พุ่งหลายทิศ แล้วบอกว่ามีกระตุกหรือถูกดึงกลับทั้งที่พุ่งปกติไหม
- **2 ผู้เล่น:** แท็บ Test → Clients and Servers เลือก 2 Players → Start จะเปิดหน้าต่างเพิ่มสองบาน ลองตีผีตัวเดียวกันแล้วดูว่าได้วิญญาณทั้งคู่ และพุ่งแล้วไม่ถูกดึงกลับ
- **มือถือ:** แท็บ Test → Device เลือกโทรศัพท์ แล้ว Play ลองลากนิ้วหมุนกล้องและกดปุ่ม ฟัน/วิชา/พุ่ง/แปลง
